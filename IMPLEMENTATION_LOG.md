  w/ terminal, EvidenceKind, EvidenceStatus, AgentKind, WeakLabelValue,
  HumanVerdict, PolicyStatus, ExplorationMode).
- `schemas/`: base `ACPModel` (canonical JSON, `compute_hash`); 30+ schemas across

  id/data/created_at + indexed FK/status/trace columns), `session.py` (sync engine,

  initial migration (35ce2faabf86) — `alembic upgrade head` builds all tables on
